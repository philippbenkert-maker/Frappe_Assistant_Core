## Version 2.6.1

### Fixes

- **MCP write feedback** — Document write tools return the real, plain-text
  Frappe permission reason instead of empty or misleading validation errors.
- **Personal ToDo creation** — Plain ToDos created by non-admin users receive
  the allocation required by Frappe's own permission rule.

### Improvements

- **Fresh MCP discovery** — MCP initialization reports the installed FAC
  version and advertises catalogue-change support for tools and resources.
- **Compact result paging** — Hook-based tool profiles always retain the
  user-bound result continuation tool.
