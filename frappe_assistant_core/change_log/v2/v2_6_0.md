# Version 2.6.0

## MCP token and credit optimization

- Added Lean, Standard, Full, and per-user Custom MCP tool profiles.
- Changed the default tool profile to Lean and the default skill mode to `replace`.
- Added a central response budget for all built-in, plugin, and externally registered tools.
- Oversized results are retained temporarily and can be read with `get_result_page`.
- Added `business_report` to combine report discovery, requirements, compact execution, summaries, and paging.
- Added configurable limits for document rows, report previews, OCR pages, Python output, descriptions, and result lifetime.
- Added per-user MCP byte/token telemetry to Assistant Audit Log and the admin usage summary.
- Removed full tracebacks and pretty-print whitespace from model-visible MCP output.
- Added an idempotent migration and fixtures so settings and User profile fields survive framework and app updates.
